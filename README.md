# Du & ich — dieses Wochenende

A static German weekend invitation with activity cards and prefilled WhatsApp messages.

## Preview locally

Run `python3 -m http.server 8000` in this directory and open http://localhost:8000.

## Edit

- `index.html`: invitation and activity descriptions.
- `style.css`: colors, layout, and card animations.
- `script.js`: moving Nein button, activity interactions, WhatsApp recipient and message templates.
- `activities/`: activity photos.

No build step or dependencies are required. WhatsApp opens an editable message; the visitor chooses a day and presses Send.

For GitHub Pages, use the `main` branch and `/ (root)` as the publishing source.

See `ASSETS.md` for image provenance. No license is granted for third-party imagery.
